# GPT 전달 내용

ChatGPT 에게 전달할 내용을 모두 이 폴더에 모았습니다. **이 폴더만 확인하면 됩니다.**

## 읽는 순서

1. [`HANDOFF_GPT.md`](HANDOFF_GPT.md): 전달 사항 전체(이번 요청 + 이전 전달 사항 기록)
   - 맨 위 **"★ GPT 할 일 전체 요약"**: 지금 할 일(1~4순위), 공통 규칙, 결과물 형식
   - **0-1 ~ 0-6장**: 이전에 전달했던 사항과 Claude 가 그동안 바꾼 것(관광지 체크 방식, 음주 옵션, 국내 도시, 공항 이동·렌터카·도시 메모, 도시 가이드, Gemini 검수)
   - **3장 "다음 조사 요청"**: 엑셀 입력 형식 상세(P0 서울·부산·제주, P1 관광지·1일권·간식·주류, P1+ 공항이동·렌터카·도시 메모)
   - **2장 검수 체크리스트**, **4장 기능 상태표**, **5장 환율**
2. [`재확인목록_gemini-2026-10-03.csv`](재확인목록_gemini-2026-10-03.csv): 1순위로 공식 페이지에서 다시 확인할 가격(판정이 `불일치`·`확인불가`인 77행)
3. [`재확인목록_설명.md`](재확인목록_설명.md): 이 목록을 그대로 믿으면 안 되는 이유(Gemini 가 페이지 접속 실패 상태에서 판정)
