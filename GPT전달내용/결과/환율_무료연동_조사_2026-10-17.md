## 저장소의 현재 연결 상태

- 서버에 `GET /api/rates`가 있습니다. 서비스는 정상 갱신값을 24시간 동안 쓰고, 제공자 오류 시 마지막 정상값을 `stale`로 반환합니다.
- 계산기 화면의 `src/ui/useRates.ts`는 API를 호출하지 않고 `STATIC_RATES`만 반환합니다. `src/core/rates/static.ts`는 `data/rates/rates-2026-10-06.json`을 import합니다. 따라서 API 경로는 있으나 현재 계산기와 연결되지 않았습니다.
- 서버 제공자 순서는 ExchangeRate-API Open Access → Frankfurter → jsDelivr입니다. ExchangeRate-API Open Access는 키 없이 하루 한 번 무료지만 출처 표시를 요구하며, 데이터를 재배포할 수 없다고 적혀 있습니다. 공개된 `/api/rates`가 이 데이터를 그대로 반환하는 구성이므로, 약관을 확인하기 전에는 이 제공자를 공개 API의 주 경로로 쓰지 않는 편이 안전합니다. [ExchangeRate-API 조건](https://www.exchangerate-api.com/docs/free)

## 무료 연동 선택지

### 우선 권장: Frankfurter와 공식 보완값을 함께 사용

Frankfurter는 API 키 없이 무료로 사용할 수 있고, 223개 통화를 104개 중앙은행·공식 출처에서 모으며 일별 갱신합니다. 상업적 이용과 자체 저장·캐시도 안내합니다. 제공자별로 조회할 수 있으므로 ECB 기준만 쓸 때는 `providers=ecb` 경로를 고를 수 있습니다. [Frankfurter 문서](https://frankfurter.dev/)

다만 사이트가 선택하는 39개 코드가 같은 날 전부 응답된다고 가정하면 안 됩니다. 조회 결과의 통화 코드를 목록과 대조하고, 빠진 코드는 공식 지역 자료의 보완값을 사용하거나 기존 정상값을 유지해야 합니다. 특히 현지 중앙은행 페이지마다 고시일이 다르므로 기준일을 통화별로 보존해야 합니다.

### 현재 배포 구조를 활용하는 방법

무료 API 호출 자체는 충분히 가능합니다. 화면의 환율 훅이 `/api/rates`를 호출하게 하고, 실패·오래된 응답에는 현재 고정 환율로 돌아가면 됩니다. Workers 무료 플랜의 요청 한도는 하루 100,000회이며, 기존 서비스는 하루 신선도 확인과 Cloudflare Cache API를 이미 갖고 있습니다. 사용량이 커지면 플랜 조건을 다시 확인해야 합니다. [Workers 한도](https://developers.cloudflare.com/workers/platform/limits/) · [Workers 가격](https://developers.cloudflare.com/workers/platform/pricing/)

### 별도 일일 갱신을 둘 수도 있음

공개 저장소에서 GitHub Actions 표준 호스티드 러너를 이용해 하루 한 번 데이터 파일을 갱신하는 방법도 무료 범위로 운영할 수 있습니다. 예약 실행은 바쁜 시간에 지연될 수 있고, 공개 저장소에서 60일간 활동이 없으면 예약 워크플로가 자동 비활성화될 수 있어 수동 실행 경로도 두는 편이 좋습니다. [GitHub Actions 과금](https://docs.github.com/en/actions/concepts/billing-and-usage) · [예약 실행 동작](https://docs.github.com/en/actions/reference/workflows-and-actions/events-that-trigger-workflows)

## 적용 권장 순서

1. `/api/rates`를 화면에서 호출하고, API 장애 시 고정값을 쓰도록 연결합니다.
2. 우선 Frankfurter의 ECB 제공자 자료를 받아 반환된 기준일과 통화 코드를 검증합니다.
3. 빠진 TWD·VND·AED·SAR·MOP·MNT·LAK·KZT·UZS·GEL·EGP는 공식 지역 출처에서 보완합니다. 기준일 미표시·지연·매입/매도 범위는 상태로 남깁니다.
4. 24시간 캐시와 마지막 정상값을 유지하고 화면에 환율 기준일·참고 환율 안내를 붙입니다.
5. 공개 API에 약관상 재배포 제한이 있는 제공자 데이터를 내보내지 않도록 확인합니다.

이번 작업은 조사 자료 두 개만 추가했습니다. 기존 환율 JSON, 사이트 코드, 워크플로는 수정하지 않았습니다.
