`네이버_재확인_2026-10-11.csv` 의 빈 칸을 채워 그대로 돌려주면 됩니다.

### 할 일 2·3·4 (새 가격)

```
"ID","국가","도시","카테고리","세부유형","항목(한글)","Item (English)","최소","최대","통화","단위","가격형태","대상","출처등급","모델사용","상태","조회일","적용/게시","출처명","출처 URL","원문 인용","비고"
```

- ID: 도시 앞자리 + 종류 + 번호. 종류는 FD(식사), SN(간식·음료), AL(주류), TR(시내 교통), AP(공항·역 이동), AT(관광)
  - 강릉 GNG, 경주 GJU, 여수 YSU, 전주 JJU, 나트랑 NHA(301~), 발리 DPS(301~), 푸꾸옥 PQC(301~), 두바이 DXB
  - 예) `GJU-FD-101`, `NHA-TR-301`, `DXB-AT-101`
- 국가: 한국 / 베트남 / 인도네시아 / 아랍에미리트
- 카테고리: `외식` / `교통` / `공항이동` / `관광`
- 세부유형
  - 식사 `저가 한끼` 또는 `중가 한끼`
  - 간식·음료 `음료` 또는 `간식`
  - 주류 `주류`
  - 교통 `버스 1회권`, `지하철 1회권`, `트램 1회권`, `무제한권`
  - 관광은 장소 종류(사찰, 박물관, 케이블카 등)
- 단위
  - 교통 1회 `성인 1인 1회` / `아동 1인 1회`
  - 1일권 `성인 1일`
  - 공항·역 `성인 1인 편도`
  - 식사 `1인분`
  - 관광 `성인 1인` / `아동 1인`
- 대상: `일반`, 또는 나이·학년 기준(예: `초등학생`, `6~12세`)
- 출처등급 `A 공식`, 모델사용 `예`(애매하면 `조건부`), 상태 `확정 1차`

마지막에 도시별로 "식사 n / 교통 n / 공항 n / 간식 n / 주류 n / 관광 n / 못 찾은 것" 한 줄 요약을 붙여 주세요.
