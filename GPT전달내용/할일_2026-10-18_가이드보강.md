# 할 일 AC: 도시 가이드 볼거리 보강 (2026-10-18)

대부분 도시가 볼거리 3곳·팁 2개뿐이라 가이드로는 얇습니다. Claude가 도쿄·오사카·파리·런던·방콕에 볼거리 2곳씩을 더해 5곳으로 만들었습니다(`src/data/city-guides.ts`, `city-guides-6.ts` 참고).
같은 방식으로 **인기 도시부터 볼거리를 2곳씩** 더해 주세요.

## 진행 상황 (2026-10-18 Claude)
- **끝남(볼거리 5곳 이상)**: 58개 도시. Claude가 1~3차로 추가했습니다(커밋 「가이드 보강 1차/2차/3차」).
- **남은 도시(볼거리 3곳)**: 세부, 괌, 사이판, 발리, 푸껫, 호찌민, 나트랑, 푸꾸옥, 달랏, 코타키나발루, 칭다오, 장자제, 알마티, 대구, 인천, 속초, 통영, 강릉, 여수, 전주.
- **1곳만 더한 도시(4곳)**: 타슈켄트, 파타야, 치앙마이, 리옹, 퀘벡시티. 한 곳씩 더 넣어 주세요.
- 볼거리 4곳인 도시(코펜하겐·스톡홀름·더블린 등 25곳)는 마지막에 1곳씩 보태면 됩니다.
- 남은 도시 중 한국 도시는 공식 관광 사이트(예: 각 시청 문화관광 페이지)를 근거로 쓰면 됩니다.

정확한 현재 개수는 아래 명령으로 확인합니다.
```
npx tsx -e "import {CITY_GUIDES} from './src/data/city-guides'; for (const [k,g] of Object.entries(CITY_GUIDES)) if (g.highlights.length<5) console.log(k, g.highlights.length)"
```

## 규칙
- 이미 있는 볼거리와 겹치지 않는, 여행자가 실제로 많이 가는 곳. 이름(ko·en·ja) + 한 줄 설명(ko·en·ja, 한국어 기준 40~70자).
- **금액을 쓰지 않습니다.** 사실은 근거로 확인하고, 근거 URL을 `src/data/city-guide-sources.ts`에 `'도시id:h4'`, `'도시id:h5'`로 넣습니다(번호는 볼거리 순서).
  - 근거 우선순위: 그 명소의 공식 사이트 → 관광청 → 공신력 있는 언론·항공사 여행 안내 → 여행 안내 사이트(URL 필수).
- 데이터 형식: `city-guides.ts`의 `BASE`는 `{ name: {ko,en,ja}, text: {ko,en,ja} }`, `city-guides-1..9.ts`는 `['이름ko','en','ja','설명ko','en','ja']`.
- 한꺼번에 넣을 때는 `python3 scripts/add-highlights.py <json>`을 쓰면 됩니다. JSON 형식: `{"도시id": [["이름ko","en","ja","설명ko","en","ja","근거URL"], ...]}`. 볼거리와 근거 키(h4, h5…)를 함께 붙여 줍니다.
- 다 쓰면 `npm run verify` → 올리기. 한 번에 5~10개 도시씩 나눠 올려도 됩니다.
