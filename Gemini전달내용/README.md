# Gemini 전달 내용

GPT 가 쉬는 동안 Gemini 에게 **가격 수집**을 맡깁니다. 받은 CSV 는 Claude 가 `data/additions/` 에 넣어 바로 사이트에 반영합니다.

- 엑셀 원본은 건드리지 않습니다. 추가 자료로만 합칩니다.
- 한 곳에서만 수집한 값이라 사이트에는 **"재검증 필요"**로 표시됩니다(계산에는 씀). 나중에 GPT·사람이 공식 페이지에서 확인하면 표시를 뗍니다.

## 꼭 지킬 것 (지난번 실패 원인)

지난번 Gemini 는 파이썬 코드로 사이트에 접속하려다 **모두 실패**했고, 기억으로 표를 채웠습니다(옛 요금이 섞임). 그래서 아래를 요청문에 넣었습니다.

1. 파이썬·코드 실행으로 접속하지 말고 **Google 검색으로 공식 페이지를 직접 확인**할 것
2. 행마다 **`원문 인용`** 칸에 페이지에 적힌 가격 문구를 그대로 복사할 것(인용이 없는 행은 변환이 거부됨)
3. 확인 못 한 값은 **행을 만들지 말 것**(추정 금지)

## 요청 순서

| 순서 | 요청 | 결과 파일 이름(Claude 가 저장) |
| --- | --- | --- |
| 1 | 서울 가격 (아래 요청문 그대로) | `prices-seoul.csv` |
| 2 | 부산 가격 (요청문의 도시·ID 만 바꿈) | `prices-busan.csv` |
| 3 | 제주 가격 (+ 렌터카) | `prices-jeju.csv` |
| 4 | 서울·부산·제주 대표 음식 | `foods-korea.csv` |
| 5 | 기존 8개 도시 주류 가격 | `prices-drinks.csv` |

결과는 CSV 코드 블록 그대로 복사해 Claude 에게 붙여 넣으면 됩니다. 한 번에 다 안 되면 나눠 받아도 됩니다.

## 요청 1 — 서울 가격 (붙여 넣을 요청문)

> 부산은 `서울→부산`, `SEL→PUS`, 제주는 `서울→제주`, `SEL→CJU` 로 바꿔서 같은 요청문을 쓰세요.
> 제주는 아래 "렌터카" 줄도 함께 요청하세요.

```
여행 경비 계산 사이트에 넣을 '서울' 현지 가격을 수집해줘.

[방법 — 반드시 지켜줘]
- 파이썬/코드 실행으로 사이트에 접속하지 말고, Google 검색으로 공식 페이지를 직접 찾아 확인해.
- 가격을 실제로 판매·운영하는 곳의 공식 페이지만 출처로 써(운영사·관광지·식당·브랜드 공식 사이트, 정부·지자체 고시).
  블로그, 뉴스 기사, 예약/배달 앱, 평균 물가 사이트는 안 돼.
- 행마다 '원문 인용' 칸에 그 페이지에 적힌 가격 문구를 그대로 복사해(예: "기본운임 1,550원").
- 확인 못 한 가격은 행을 만들지 마. 추정·반올림·환산 금지.

[수집할 항목 — 서로 다른 가게·상품으로]
- 교통 1회 요금 3건 이상: 지하철, 시내버스, 광역버스 등 (교통카드 성인 기준)
- 교통 1일권이 있으면 1건 이상 (예: 단기 이용권)
- 공항↔시내 이동 2건 이상: 공항철도·공항버스 등 편도 성인 요금 (카테고리 '공항이동', 아동 요금 있으면 별도 행)
- 식사 5곳 이상: 저가~중가 한 끼 (국밥·냉면·김밥·프랜차이즈 등, 메뉴판 정가)
- 간식·음료 3건 이상: 카페 아메리카노, 길거리 간식 등
- 주류 3건 이상: 식당 소주 1병, 맥주 1병/1잔, 편의점 맥주 1캔 등 (단위에 용량)
- 기념품 3건 이상: 서로 다른 상품
- 관광지·테마파크 입장료 5~10곳: 궁궐, 전망대, 테마파크, 박물관 등 (성인 행, 아동 요금 있으면 별도 행)

[출력 형식]
아래 머리글 그대로, 쉼표 구분 CSV 코드 블록으로 줘. 머리글 순서·이름 바꾸지 마.

ID,국가,도시,카테고리,세부유형,항목(한글),Item (English),최소,최대,통화,단위,가격형태,대상,출처등급,모델사용,상태,조회일,적용/게시,출처명,출처 URL,원문 인용,비고

칸 채우는 법:
- ID: SEL-TR-001 처럼 (TR=교통, AP=공항이동, FD=식사·간식·주류, AT=관광지, SV=기념품), 번호는 001부터
- 국가: 한국 / 도시: 서울 / 통화: KRW
- 카테고리: 교통, 공항이동, 외식, 관광, 기념품 중 하나
- 세부유형: 교통은 '지하철 1회권'·'버스 1회권'·'무제한권', 외식은 '저가 한끼'·'중가 한끼'·'간식'·'음료'·'주류', 관광은 '궁전'·'전망대'·'테마파크'·'박물관' 등, 기념품은 '식품'·'잡화'
- 최소·최대: 숫자만(쉼표 없이). 가격이 하나면 둘 다 같은 값. 날짜·수요에 따라 바뀌면 최소~최대
- 단위: 교통은 '성인 1인 1회', 1일권은 '성인 1인 1일', 식사는 '1그릇'·'1인분', 관광은 '성인 1인'·'아동 1인', 주류는 '1병 360ml'처럼 용량
- 가격형태: 고정형 / 거리형(거리별 요금) / 요일형(평일·주말 따로) / 수요형(날짜·수요 변동)
- 대상: 일반 / 아동 7-12세 처럼 나이
- 출처등급: 공식 페이지면 'A 공식' / 모델사용: 예 / 상태: 확정 1차
- 조회일: 오늘 날짜 YYYY-MM-DD / 적용/게시: 요금 적용 시작일을 알면 'YYYY-MM-DD 이후', 모르면 2026
- 비고: 세금·봉사료 별도면 적고, 그 밖의 조건(교통카드 기준 등)
```

### 제주에 추가할 줄

## 요청 4 — 대표 음식

```
서울·부산·제주 각각 대표 음식 3~5개를 정리해줘. 근거는 한국관광공사(visitkorea) 등 공식 관광 안내 페이지만 써줘.
아래 머리글 그대로 CSV 코드 블록으로 줘.

국가,도시,음식(한글),Food,추천 이유,예산대,연결 가격 ID,가격조사 상태,추천 출처,출처 URL,비고

- 국가: 한국 / 도시: 서울·부산·제주
- 추천 이유: 한 문장 / 예산대: 저, 저~중, 중, 중~고, 고 중 하나
- 연결 가격 ID·비고: 비워 둬 / 가격조사 상태: 대기
```

## 요청 5 — 기존 8개 도시 주류

```
도쿄·오사카·방콕·다낭·타이베이·싱가포르·파리·런던 각각 주류 가격 3건씩 수집해줘
(식당·펍 맥주 1잔, 편의점·마트 맥주 1캔, 와인 1잔 등 서로 다른 가게·상품).

ID 앞 글자: 도쿄 TYO, 오사카 OSA, 방콕 BKK, 다낭 DAD, 타이베이 TPE, 싱가포르 SIN, 파리 PAR, 런던 LON.
```
