# 환율 (조사 고정값)

화면은 외부 환율 API 를 부르지 않고, 이 폴더의 **조사한 환율표**를 씁니다(운영자 결정, 2026-10-04).

- 현재: `rates-2026-10-02.json` — 2026-10-02 기준
  - 유럽중앙은행(ECB) 기준환율(1 EUR 당 25개 통화) → 1 USD 기준으로 나눠 씀
  - ECB 에 없는 통화: TWD(대만 중앙은행 은행간 마감가), VND(Vietcombank 매입·매도 중간값), AED·SAR(공식 달러 고정환율)
  - 교차 확인: 원/달러 환산값 1,348.3 ↔ 서울 외환시장 1,350.60원, 홍콩달러 7.847 ↔ 연동 범위 7.75~7.85

## 갱신 방법

1. 새 기준일의 ECB 기준환율 표(1 EUR 당)와 위 4개 통화 값을 공식 출처에서 확인한다(한 출처만 보지 말고 2곳 이상).
2. `rates-YYYY-MM-DD.json` 을 새로 만들고(이전 파일은 기록용으로 둔다) `src/core/rates/static.ts` 의 import 를 새 파일로 바꾼다.
3. `npm run verify`.
