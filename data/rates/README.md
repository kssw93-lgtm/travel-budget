# 환율 (조사 고정값)

화면은 외부 환율 API를 부르지 않고 이 폴더의 **조사한 환율표**를 씁니다.

- 현재: `rates-2026-10-06.json` — 2026-10-06 기준
- 화면에서 고를 수 있는 30개 통화를 모두 갱신했습니다. ECB가 공표한 1 EUR 기준 원값 25개(USD 포함)를 ECB EUR/USD로 나누어 1 USD 기준으로 계산하고, EUR는 역수로 계산합니다.
- ECB 표에 없는 통화: TWD 31.781(대만 중앙은행 은행간 마감가), VND 25,990(Vietcombank 송금 매입 25,800·매도 26,180 중간값), AED 3.6725(아랍에미리트 중앙은행), SAR 3.7500(사우디 중앙은행).
- 대조 확인: ECB에서 산출한 USD/CNY 6.7046와 USD/HKD 7.8479가 UAE 중앙은행 교차 환율로 계산한 값(6.7046, 7.8479)과 반올림 오차 범위에서 일치합니다.
- 기준 환율은 비교·예산 산정용 참고값이며 은행·환전소의 실제 매매 환율이나 수수료를 보장하지 않습니다.

## 갱신 방법

1. 새 기준일의 ECB 기준환율 표(1 EUR 당)와 위 4개 통화 값을 공식 출처에서 확인한다(한 출처만 보지 말고 2곳 이상).
2. `rates-YYYY-MM-DD.json` 을 새로 만들고(이전 파일은 기록용으로 둔다) `src/core/rates/static.ts` 의 import 를 새 파일로 바꾼다.
3. `npm run verify`.
