# Gemini 교차 검수 안내 (Claude → Gemini)

## 역할 나누기

| 담당 | 하는 일 | 결과물 |
| --- | --- | --- |
| ChatGPT | 가격 **수집**: 새 도시, 관광지, 주류, 공항 이동, 렌터카, 도시 메모 | 조사 엑셀 새 버전 (`GPT전달내용/HANDOFF_GPT.md` 형식) |
| **Gemini** | 수집된 가격의 **교차 검수**: 공식 페이지에서 같은 가격이 맞는지 다시 확인 | 검수 CSV 1개 (아래 형식) |
| Claude | 엑셀·CSV 변환, 계산·화면, 테스트 | 사이트 |

한 모델이 조사한 값을 다른 모델이 따로 확인해야 같은 실수(오래된 페이지, 다른 상품 혼동, 통화·세금 착오)가 걸러집니다.
GPT 가 자기 자료를 다시 검수하는 것보다 효과가 큽니다.

## 주의: 실제로 페이지를 열 수 있을 때만 유효

2026-10-03 첫 검수에서 Gemini 의 코드 실행 환경은 출처 URL 에 하나도 접속하지 못했습니다(`name resolution` 실패).
그 상태에서 나온 판정은 기억에 의존한 값이라 검수로 쓰지 않았습니다(`GPT전달내용/재확인목록_설명.md`).

- Gemini 에는 **Google 검색(그라운딩)으로 페이지를 직접 확인**하라고 요청하세요. 코드 실행(파이썬)으로 접속하는 방식은 막혀 있습니다.
- `메모` 칸에 **페이지에 적힌 가격 문구를 그대로 인용**하게 하세요. 인용이 없는 "불일치"는 반영하지 않습니다.
- 접속에 실패했다고 말하거나 코드 출력에 접속 오류가 보이면, 그 결과는 받지 말고 다시 요청하세요.

## 할 일: `data/cross-check-queue.csv` 채우기

- 이 파일은 `npm run data:convert` 할 때마다 자동으로 만들어집니다.
- 계산·목록에 실제로 쓰이는 표본 중 아직 "일치" 판정이 없는 행만 들어 있습니다(현재 123행).
- 왼쪽 열(ID~조회일)은 고치지 말고, 오른쪽 빈 칸 5개만 채웁니다.

| 열 | 채우는 법 |
| --- | --- |
| `판정` | `일치` / `불일치` / `확인불가` 중 하나(이 세 단어만 허용, 다르면 변환이 멈춤) |
| `확인 가격` | 공식 페이지에서 직접 본 가격과 통화. 예: `1000 JPY`, `€16~22` |
| `확인 URL` | 가격이 실제로 적힌 공식 페이지 주소(판매 주체: 운영사·관광지·식당·브랜드). 블로그·여행 예약 사이트·평균 가격 사이트는 안 됨 |
| `확인일` | `YYYY-MM-DD` |
| `메모` | 불일치·확인불가 이유. 예: "2026-04 요금 개정으로 1,100엔", "페이지 접속 불가", "어린이 요금만 표시" |

판정 기준:
- **일치**: 같은 상품·같은 대상(성인/아동)·같은 단위의 가격이 원값 그대로 확인됨. 세금 포함 여부도 같아야 함.
- **불일치**: 공식 페이지 가격이 다름, 다른 상품이었음, 단위(1회/1일/왕복)나 대상이 다름.
- **확인불가**: 페이지가 열리지 않음, 가격이 로그인·예약 단계에서만 보임, 공식 출처를 찾지 못함.
- 추정·환산·반올림한 값은 쓰지 않습니다. 모르면 `확인불가`.

## 돌려주는 방법

1. 채운 파일을 `gemini-YYYY-MM-DD.csv` 이름으로 저장합니다(UTF-8, 쉼표 구분, 머리글 그대로).
2. 운영자가 저장소 `data/reviews/` 폴더에 넣거나 Claude 에게 전달합니다.
3. 변환할 때 다음과 같이 처리됩니다.
   - `불일치`·`확인불가`로 판정된 표본은 사이트에 "재검증 필요"로 표시됩니다. 가격 자체는 자동으로 바꾸지 않습니다. 고칠 값은 GPT 가 엑셀 다음 버전에 반영합니다.
   - `일치`로 판정된 표본은 다음 검수 목록에서 빠집니다.
   - 진행 현황은 `data/research-queue.md` 4장에 나옵니다.

일부만 채워서 보내도 됩니다. 판정 칸이 빈 행은 무시합니다.

## Gemini 에게 붙여 넣을 요청문(예시)

> 첨부한 CSV 의 각 행은 여행 경비 사이트에 쓰는 가격 표본입니다. 각 행의 `출처 URL` 또는 해당 판매 주체의 공식 페이지를 직접 열어,
> 같은 상품·같은 대상·같은 단위의 가격이 맞는지 확인해 오른쪽 5개 열(판정, 확인 가격, 확인 URL, 확인일, 메모)만 채워 주세요.
> 판정은 `일치`/`불일치`/`확인불가` 세 단어만 씁니다. 공식 판매 주체가 아닌 사이트(블로그, 예약 사이트, 평균 물가 사이트)는 근거로 쓰지 마세요.
> 추정하거나 환산하지 말고, 확인할 수 없으면 `확인불가`로 두세요. 왼쪽 열과 머리글은 바꾸지 말고 같은 CSV 형식으로 돌려주세요.

## 도시를 늘릴 때

1. GPT 가 새 도시를 엑셀에 추가합니다.
2. Claude 가 변환합니다. 새 도시 표본이 `cross-check-queue.csv` 에 자동으로 추가됩니다.
3. Gemini 가 그 CSV 를 검수합니다.
4. Claude 가 반영합니다.

엑셀에 `조사 단계`=`파일럿`으로 들어간 도시는 도시 선택 목록과 가이드 페이지(`/guide/도시`)가 자동으로 생깁니다.
경비 금액은 바스켓별 독립 표본 3건을 채운 뒤부터 나옵니다. 그 전에는 "가격 자료 보강 중"으로 보입니다.
