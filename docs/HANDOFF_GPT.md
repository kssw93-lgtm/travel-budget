## 0-1. 이전 작업: 관광지는 "체크하면 추가"로 변경

- 관광지 비용을 **자동으로 넣지 않습니다**(이전: 하루 1곳 × 평균 입장료). 체크하기 전에는 0원이고, 체크한 곳의 입장료만 인원 기준으로 더해집니다.
- 관광지 카드는 처음부터 펼쳐져 있고 곳별 성인·아동 입장료, 체크 시 "+금액 (전체 n명)", 상단에 "n곳 선택 · +합계"를 표시합니다.
- 도시 판정(계산 가능 여부)은 외식·교통·기념품 표본만으로 합니다. 관광지 표본이 적어도 계산은 막히지 않고, 목록에 보이는 곳이 적을 뿐입니다.
- 첫날·마지막 날 60% 규칙은 유지하고, 내역 표기만 "3끼 × 60%" 로 바꿨습니다.
- **조사 요청 영향**: 관광지·테마파크 입장료(P1-1)는 이제 "목록에 보이는 선택지"가 됩니다. 도시마다 대표 명소·테마파크를 많이(5~10곳) 넣어 주실수록 좋습니다.

## 0. 결과 화면 구체화

- **항목별 "자세히 보기"**: 결과의 외식·교통·관광지·기념품 행마다 펼침 내역.
  - 외식: 1일차·2일차… 일차별 1인 끼니 수(첫날·마지막 날 1.8끼, 그 외 3끼) × 1끼 가격 범위 = 그날 합계(전 인원)
  - 교통: 일차별 1인 이용 횟수 × 1회 가격 = 그날 합계
  - 관광지: 직접 고른 곳은 곳별 성인·아동 입장료와 소계, 고르지 않으면 일차별 방문 수 × 1곳 가격
  - 기념품: 성인 수 × 1인 개수 × 1개 가격
- **예비비를 항목별로 표시**: 각 항목에 "+ 예비비 10%"와 "예비비 포함" 금액(항목별 예비비의 합 = 전체 예비비).
- **음주 포함(성인) 체크**: 외식에 주류 바스켓(성인 1인 하루 1/2/3잔, 절약/일반/여유형)을 더함. 아동은 제외.
  **현재 엑셀에 주류 가격이 0건**이라 금액은 더하지 않고 "주류 가격 자료가 아직 없어…" 안내만 나옴 → 아래 P1-4 조사 요청.
- **근거·출처·경고 패널은 기본 접힘**("가격 근거·출처·경고 보기"), 결과 중간의 "계산 방법" 링크는 제거(방법론 페이지는 이후 제거).

## 1. 이번에 Claude 가 한 일

### 새 기능 ① 관광지·테마파크 입장료 목록 + "갈 곳 선택"
- 계산기 화면 입력 카드 아래 **"관광지·테마파크 입장료"** 카드(접힘/펼침).
- 도시별로 계산에 쓰이는 입장권 표본을 한 줄씩 보여줌: **성인 요금, 같은 상품의 아동 요금, 선택 통화 환산, 출처 링크, 확인일**,
  "날짜·수요에 따라 변동(범위)", "재검증 필요", "조건부 자료" 표시.
- 체크한 곳이 있으면 **관광 비용 = 고른 곳의 입장료 합계**(1곳 1회, 성인 요금×성인 + 아동 요금(없으면 성인 요금)×아동).
  고른 곳이 없으면 기존처럼 평균 추정. 선택은 URL(`attr=ID,ID`)에 남아 공유·새로고침에 유지, 도시를 바꾸면 초기화.
- 기존 제외 규칙 그대로 적용(EEA 전용 요금, 상한 문구 등은 목록에 없음). 케이블카·곤돌라는 관광지로 나옴.
- 여행 기간에 판매하지 않는 곳(유효 기간 밖)은 합계에서 빼고 경고.

### 새 기능 ② 현지 물가 한눈에
- 결과 아래 **"○○ 현지 물가 한눈에"** 표: 한 끼 식사 / 간식·음료 1개 / 대중교통 1회 / 1일 이용권(1일 환산) / 관광지 입장료(성인 1회) / 기념품 1개의
  **대표 가격(중앙값)·범위**를 현지 통화와 선택 통화로 표시. 독립 표본 3건 미만은 "참고용"으로 표시.
- "기본 외식비가 얼마냐"에 바로 답하는 표. 값은 계산과 같은 가격 표본·같은 규칙에서 나옴(별도 수치 없음).

   같은 가게·같은 상품의 용량 차이는 1건으로 셉니다.

### P2 — 코드 추가가 필요(조사해 주시면 다음 작업에서 구현)
4. **공항↔시내 교통(여행당 1회)**: 도시별 대표 노선 편도 성인 요금(철도·공항버스). 제안: 카테고리 `공항이동`.
   ※ 현재 변환기는 모르는 카테고리를 건너뛰므로 미리 넣어도 안전합니다(경고만 출력).
5. **도시 메모(새 시트 제안 `도시 메모`)**: 열 예시 — 도시 / 항목 / 값 / 단위 / 출처 URL / 조회일
   - 팁 관행(식당 % 또는 없음), 서비스료·부가세 포함 여부
   - 숙박세·관광세(1인 1박 금액, 예: 파리 taxe de séjour, 도쿄 숙박세)
   - 입국 수수료(국적별로 다름 → 한국 여권 기준만 우선: 영국 ETA 등)
   - eSIM/유심 대표 가격(데이터 용량·일수)
