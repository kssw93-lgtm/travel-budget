# 일본어 번역 용어 근거 (2026-10-04)

일본어 화면(`src/i18n/ja.ts`, `src/i18n/places.ts`)의 핵심 용어를 일본 공식 사이트·사전의 실제 용례와 대조한 기록.
이 작업 환경에서는 사전 사이트(jisho.org·weblio.jp) 직접 접속이 막혀 있어 **웹 검색 결과의 공식 페이지 용례**로 확인했다.
새 문구를 넣을 때는 이 표의 용어를 그대로 쓴다.

## 데이터 이름

가격 표본·대표 음식·도시 메모에는 일본어 열이 없어 일본어 화면에서는 **영문 이름**을 보인다(한글은 일본어 사용자가 읽기 어렵기 때문).
도시·나라 이름만 `places.ts` 에서 일본어로 보탠다.
