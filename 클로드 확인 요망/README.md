## 목적과 상태

실제 공개 사이트의 16개 도시 가이드와 저장소의 조사 대기 자료를 비교해, 계산에 필요한 가격과 사이트 품질을 높이기 위한 확인 사항을 모았습니다. 이 폴더는 Claude가 확인·수정 결과를 기록하고 전체 항목을 닫을 때까지 보존합니다. **검토 완료 전 삭제하지 마세요.**

이 점검은 누락을 찾는 목록입니다. 새 현지 가격을 수집하거나 가격 원값·엑셀을 고친 작업은 아닙니다. 가격을 추가할 때는 HANDOFF_GPT.md의 공식 판매자 출처와 현지 통화 원값 규칙을 지켜 주세요.

## 우선 확인 요약

1. **성인 관광지 입장료가 목표보다 적은 도시 5곳**: 이스탄불 6곳(+6), 상하이 5곳(+7), 서울 7곳(+5), 부산 7곳(+5), 제주 6곳(+6). 12곳 기준까지 총 29개 성인 명소가 더 필요합니다.
2. **관광지 아동 요금 미표시 90칸**: 유료·무료·연령 제한·아동 대상 없음 여부를 공식 페이지에서 확인해 값 또는 명시적 상태로 정리해 주세요. 미표시를 자동으로 0원 처리하지 마세요.
3. **대표 음식 추천 73개 중 43개가 가격 대기**: 상세 목록은 `메뉴_가격_확인대기.csv`. 식당/브랜드가 직접 공개한 메뉴 가격만 확인해 주세요.
4. **공식 출처 재검증 기록이 비어 있음**: `data/cross-check-queue.csv` 729행 모두 `판정` 칸이 비어 있습니다. URL 존재만으로 확인 완료로 간주할 수 없으므로 공식 원문을 열어 가격·대상·단위·적용 조건을 확인하고 판정/확인 가격/확인 URL/확인일을 기록해야 합니다.
5. **계산은 가능하나 표본 보강이 필요한 바스켓**: 최신 자동 목록 `data/research-queue.md`는 계산 차단 항목은 없다고 하지만, 1일 교통권 0~2건인 도시가 15곳이고 간식·음료 또는 주류도 일부 3건 미만입니다. 아래 도시별 파일의 바스켓 열을 우선 보완해 주세요.
6. **교통권 비교·도시 메모 공백**: 사이트에서 교통 이용권 손익/비교 안내가 없는 도시는 다낭·뉴욕·이스탄불·상하이·제주 5곳입니다. 도시 메모가 없는 곳은 다낭·이스탄불·상하이·부산·제주입니다. 패스 상품이 실제 없는 것인지, 미조사인지 구분하고 현지 수수료·팁·공항 이동 등 여행 예산에 필요한 정보를 확인해 주세요.
7. **주류 다양화 요청 대조 필요**: `Perplexity전달내용/주류_목록.md`의 도시별 주류·용량 목표와 현행 가격 표본을 품목별로 비교해야 합니다. 대조용 체크리스트는 `주류_목록_재점검.csv`에 있습니다. 현재 목록은 요구사항이지, 각 품목의 현재 미수집을 확정한 판정은 아닙니다.

## 표시 날짜 불일치

도시 가이드 가격 데이터 기준일은 2026-10-04, 홈/푸터의 가격 기준일은 2026-10-07, 환율 출처일은 2026-10-02로 표시됩니다. 세 날짜가 무엇을 뜻하는지 확인하고, 실제 데이터 갱신일과 환율 기준일을 구분해 사용자에게 일관되게 보여 주세요.

## 계산 및 가격 표시에 관한 확인

- 교통 손익분기/패스 비교 값은 단일 요금의 중앙값 등을 사용한 파생 참고치입니다. 공식 고정 가격처럼 보이지 않도록 산식, 적용 횟수, 기준 요금과 참고치임을 설명해 주세요.
- 관광지 입장료는 기본 여행 경비에서 제외되고 사용자가 선택해 추가하는 방식으로 보입니다. 기본 제외 안내와 체크 후 계산 반영이 일치하는지 확인해 주세요.
- 아동 가격이 없는 경우는 무료, 유료이나 자료 없음, 연령 기준 차이, 성인 전용을 구별해 주세요.
- 가격 표본의 출처는 모두 URL이 있지만, 출처 페이지의 접근성·공식성·가격 일치 여부를 확인해야 합니다. 특히 `data/research-queue.md`의 조건부/B등급/시작가/세금 별도 행부터 우선 대조하는 편이 좋습니다.
