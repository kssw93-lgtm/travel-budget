# 퍼플렉시티 전달 내용 (2026-10-13)

다른 도구(크롬·GPT)가 **공식 페이지를 못 찾은 항목**만 모았습니다. 퍼플렉시티는 검색이 강하니 **공식 출처 주소와 원문 가격 문구**를 찾아 주세요.

## 규칙
- 공식 출처만: 운영 기관·식당·관광지 공식 홈페이지, 정부·지자체 공지, 공식 PDF, 공식 SNS 게시물.
- 블로그·뉴스·리뷰·여행 예약 사이트(Klook·KKday·Trip.com 등)는 **근거로 쓰지 않습니다**(찾는 실마리로는 괜찮음).
- 금액은 원문 그대로, 원문 문구를 함께. 날짜(게시일·시행일)가 보이면 적기.
- 확정이 안 되면 "미확정 + 이유 + 확인한 URL".
